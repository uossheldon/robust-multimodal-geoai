# Canonical result inventory

The files below contain saved measurements, not outputs generated by the website build. Values retain their recorded precision. Figures and the results explorer read these sources through `scripts/presentation_data.py`; the site JSON is a checked presentation copy.

| Evidence | Canonical files | Interpretation |
|---|---|---|
| Tile selection and class balance | `tile_manifest.csv`, `per_date_statistics.csv` | Fixed split, windows and common-valid class counts; no raster pixels |
| Final clean comparison | `final_test/clean_test_results.csv` | Single runs or mean/sample SD across three training seeds |
| Final robustness aggregates and evaluation identity | `final_test/final_summary.json` | Optical conditions pool nine training × corruption runs; clean/missing use three training seeds |
| Final individual runs and dates | `final_test/robustness_test_results.csv`, `final_test/per_date_test_results.csv` | Evidence underlying pooled and per-date reporting |
| TerraMind validation | `terramind_validation.json` | Complete per-seed values and established three-seed aggregates |
| Three-seed fusion validation | `reproducibility/aggregate_results.csv`, `reproducibility/per_seed_results.csv` | Original fusion and modality dropout; within-seed corruption averages |
| Occlusion-aware validation | `occlusion_training/aggregate_results.csv`, `occlusion_training/per_seed_results.csv`, `occlusion_training/robustness_auc.csv` | Three-method comparison and established curve areas; baseline rows reproduce the preceding aggregate |
| Initial robustness control | `robustness/optical_occlusion.csv`, `robustness/optical_occlusion_summary.csv`, `robustness/missing_modality.csv` | Single selected models, including unaffected SAR control |
| Conventional validation | `s2_deeplab_weighted/metrics.json`, `s1_deeplab_weighted/metrics.json`, `s1_s2_early_fusion/metrics.json` | Selected single-run metrics, weights and training metadata |
| Optical imbalance selection | `s2_deeplab_balanced_sampling/validation_comparison.csv` | Unweighted, weighted and sampling runs; binary metrics and prediction fractions |
| Individual uncertainty | `uncertainty/aggregate_metrics.csv`, `uncertainty/per_seed_metrics.csv`, `uncertainty/risk_coverage.csv` | Three-seed validation diagnostics; corruption seed 101 |
| Ensemble uncertainty | `ensemble_uncertainty/metrics.csv`, `ensemble_uncertainty/error_detection.csv`, `ensemble_uncertainty/risk_coverage.csv` | One probability ensemble; error scores all target ensemble errors |

Supporting records preserve training settings and diagnostic evidence: `s2_deeplab/{metrics,baseline_diagnostics,test_metrics}.json`, `s2_deeplab_balanced_sampling/{metrics.json,strata_summary.csv}`, `modality_dropout/clean_metrics.json`, and `reproducibility/summary.json` / `occlusion_training/summary.json`. The earlier unweighted optical test result is retained explicitly; September evaluation was not a pristine first-touch holdout.

`validation_vs_s2.csv` and `validation_modality_comparison.csv` in the SAR/fusion folders retain binary metrics and comparison columns used by reproduction entry points. They are not extra independent runs. The canonical final comparison is the `final_test/` record.

Source dataset redistribution rights remain unresolved. These numeric summaries grant no rights to the external imagery or labels. See [methods](../docs/METHODS.md), [scientific qualifications](../docs/SCIENTIFIC_AUDIT.md), and [data provenance](../docs/DATA_PROVENANCE.md).
